# 访谈粗剪：分段异源与叙事选句

跨场规则（选型「不用模板」的人物叙事粗剪）。场次专名、禁窗、ASR 别字表写进本场 `sources.md` / subagent prompt，**不**写进本篇。

## 适用

- 访谈 / 人物叙事初剪，不是峰会关键词高光。
- 片源常为「前半单机 + 后半同步双机」或其它时段不一致的多文件。
- 用户给了精剪方案：只当**时长预算 + 检索词**，不做标题卡 / 图卡 / 履历播报。
- **禁止**套峰会 `run_dualcam_lapi.py plan` 与导演词里的 FDE/OPC `theme_keywords`（会打乱人物叙事）。

## 同素材续剪

用户通常只说「以前剪过」/「同素材再做一条」。**不要求** theme 路径。

1. 扫 `temp/*/sources.md`、`sources.json`（`person` / `parts`）、相关 `output/`。
2. **唯一命中** → 读 sources + 按 `stt` 溯源复用转写。
3. **对不上 / 多候选** → **停下来问一句确认**。
4. 默认不重 STT、不当全新采访。

首次讲清片源关系时：当场写枢纽 `temp/<素材主题>/sources.md`，并在 `sources.json` 写 `layout` + `stt`；禁止只留在聊天里。

## temp 目录命名

| 类型 | 是否打戳 | 约定 |
|---|---|---|
| **素材枢纽**（sources + 合并转写 + aligned） | **否** | 长期稳定，供续剪扫到 |
| **成片工作区**（timeline / cut / 本场字幕） | **是** | `{短名}_{YYYY_MM_DD_HH_MM}`（Asia/Shanghai）；同分钟碰撞加 `__2` |

- 新建：[`src/lapi/theme_dir.py`](../../src/lapi/theme_dir.py) → `allocate_temp_dir`。
- 续剪 / cut：短名 → `resolve_temp_dir` 取最新戳。
- **`output/` 交付名不打戳**。
- cleanup `--theme` **须精确目录名**（含戳），不做短名解析。

## STT

**优先：** 对各原始分段算 MD5 → 查/写 `cache/transcripts/<md5>.json` → 按 `T0` 合成工作区 `transcript.json`。

**若已对合并片 STT：** 保留 cache；在 `sources.json.stt` 登记 concat md5、`from_parts`、原片路径。

开剪前查 cache：`stt.parts[].md5` → `stt.concat.md5` / `transcript_md5` → 工作区 transcript → 全无才打 API。

新场尽量「先分段 STT 再合成」；禁止「没转过」盲目重跑。

**禁止 Whisper 回退：** 正式 STT 只走 ElevenLabs。401 / 额度 / 网络失败 → 停工换 key 或问用户。详见 [`ElevenLabs-STT-401与禁止Whisper回退.md`](./ElevenLabs-STT-401与禁止Whisper回退.md)。

## temp / cache 性价比

**永久保留：** `cache/transcripts/`、`sources.md`、`sources.json`、合并转写、`timeline.json`、`review_script.md`、`*_concat.txt`、已纠错字幕。

**交付后可删：** `aligned/*.mp4`、`source_concat.mp4`、`cuts/`、`narrative/`、jinju bake/preview、临时 audio。

同日多批：成片区可批批清；枢纽 `aligned` **留到当日最后一批再清**。入口：[`cleanup-temp-media.md`](../workflows/cleanup-temp-media.md)。

## 检查清单

### 1. 片源与对齐

- [ ] 哪几段是完整音频轴、哪几路仅后半有特写 → 写入 `sources.md`。
- [ ] 需要虚拟双机时：前半不得臆造真特写（可用全景垫）。
- [ ] 记下分界 `T0`；**禁止跨 `T0` 选段**。
- [ ] `audio_source` 写入 `sources.json`（完整音频在哪一路就写哪一路）；检查清单与 cut **读字段**，不写死 wide/closeup。

### 2. 转写

- [ ] **跳过**峰会 `plan` 规则导演。
- [ ] 优先对与音源一致的各段原片 STT；后半词级时间码 `+ T0` 合并。
- [ ] 不要对「假特写前半」单独 STT。
- [ ] 合并片 STT 须登记 `stt.concat`。

### 3. 选句

- [ ] 全片一句中心；案例只证明它。
- [ ] 精剪方案 → 时长预算 + 关键词；不做标题卡 / 关键词上屏 / jinju 焊尾。
- [ ] 先关键词打点，再 dump 词窗锁边；禁止无目标通读整场。
- [ ] 句首句尾完整；禁半截起刀；半截修法：预算内挪到最近完整句界，**禁止**为补全句撑爆时长。
- [ ] 优先被访第一人称；少留主持人问句。
- [ ] **音质**（回音 / 空麦轰鸣 / 叠音 / 混响）靠人耳：锁边后每拍抽 ≥3s 试听；不过则换窗或丢拍。无可靠自动回音门；转写听不出回音。本场已知坏窗写进本场 prompt，不写本 FAQ。

### 4. 镜头

- [ ] `t < T0`：只能用当时已有的机位（通常仅 wide）。
- [ ] `t ≥ T0`：主特写、辅全景（定场 / 多人关系可用全景）。
- [ ] 单镜建议 ≥ 2.5s；不句中硬切。

### 5. 出片契约

- [ ] `load_timeline` 要求源时间升序、段不重叠。
- [ ] 叙事跳切重排时：勿直接 `run_dualcam_lapi.py cut`。一次性绕过脚本**未升格则不写死路径**；同类再跑通后再考虑进 `scripts/`。
- [ ] 段已升序时才可用标准 `cut`。

### 6. 闸门与交付

- [ ] 交稿前：`scripts/check_interview_timeline.py --theme <戳名>` 退出 0。
- [ ] 先写 / 改 `review_script.md`，**人过目后再 cut**。
- [ ] 字幕：只改别字，不动时间码 / 不增删 cue；别字表来自本场，不套别场 ASR 表。
- [ ] 访谈默认跳过 `run_jinju.py`。
- [ ] 交付后跑 cleanup（dry-run → `--apply`）；同日还有下一批则枢纽 aligned 批末再清。

## 多路 subagent 并行

| 角色 | 职责 |
|---|---|
| **父（串行准备）** | 扫枢纽、复用转写、按需拼 aligned、`allocate_temp_dir` 建 N 区、写各区 sources、给秒级锚点 |
| **Subagent（一路一条）** | 只改自己的 `temp/<戳>/`：打点 → dump → timeline + review + cut 脚本；**禁止 cut / 重 STT / 改对方目录 / 改 `src/`**；交稿前自跑验收 |
| **父（串行验收）** | 对每路跑同一验收脚本；失败才 resume；禁止整批手工 dump |
| **Cut（并行）** | 各跑本路 cut；字幕别字按本场表一次改完再 pack |

```bash
.venv/bin/python scripts/check_interview_timeline.py --theme <戳名或短名>
```

Subagent prompt 硬约束摘要：目标时长 ± 容差；dump 锁边；禁半截、禁跨 `T0`；机位与 `audio_source` 读 `sources.json`；交稿前验收退出 0；人耳试听音质；粗剪不做标题卡 / 结构图。

- 不写完整「并行编排」CLI。
