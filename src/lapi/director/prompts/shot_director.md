# 镜头导演总则（Agent 对话用，不调外部模型 API）

语义快剪之后、交付 cut 之前：给 `timeline.json` 各段挂上机位。  
**本步只做双机位 A/B**：`closeup`（特写）| `wide`（全景）。音频始终特写轨。

## 不做

- 推拉摇、缩放、摇移、第三机、成片级运镜——留给精剪。

## 目标

混剪时让观众感到「有人在场、有重点」：

1. **主特写、辅全景**：干货与人脸默认特写。
2. **全景有目的**：定场、换气、场子感——不是为切而切。
3. **切在缝上**：只在段与段之间，或词间隙停顿处拆段换机位；禁止句中硬切。
4. **少切**：单镜建议 ≥ 2.5s；能整段一种 shot 就不拆。

## 何时特写 / 全景

| `closeup` | `wide` |
|---|---|
| 金句、定义、FDE/OPC 等主题词点名 | 开块定场（一段开头短铺垫） |
| 论证干货、能力画像、收束判断 | 特写过长后的换气（须有停顿） |
| 人脸表情、强调句 | 礼仪、场子、听众感、列举过渡 |

峰会主题词（FDE、OPC、流程革命、懂业务、个人/组织提效等）→ **优先特写**。

## 操作方式

对审阅稿**每一段**套用 [`shot_director_segment.md`](./shot_director_segment.md)：

1. 需要拆段时用 `scripts/dump_words_window.py` 找停顿。
2. 输出 JSON，写回 `temp/<theme>/timeline.json`（只改 `shot` / 按停顿拆段，**不要**为镜头改语义起止意图）。
3. 全部段改完后：`scripts/refresh_review.py` → 确认 → `cut`（组装干净 `output/`）。

## 与规则引擎关系

- `plan` 里的 [`shots.md`](./shots.md) 只是粗挂机位；本步 Agent 修订为准。
- 不在仓库代码里调用外部模型 HTTP API。
