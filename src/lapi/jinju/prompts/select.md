# 金句筛选总则（Agent 对话用，不调外部模型 API）

本模块与双机位叙事初剪 **文件隔离**（不改主 `timeline.json`），但是峰会交付的**必做闸门**：推荐金句焊进特写/全景/混剪三条成片末尾，并交付多轴备选条（换结尾换最后一截）。**不**另出第四条成片。  
目标：从原片挑 **2～3 条可单独上屏的压轴金句**，听感（降调落地 / 铿锵有力）优先于主题覆盖。

「京剧」口语 = **金句**（同音）；不是戏曲素材。

## 目标

1. **可独立上屏**：不听前后文也能懂；一句收束，像盖章。
2. **听感合格**：句末降调落地（`falling`），或短句铿锵（`punchy`）。
3. **比主片更亮**：优先未进入主 `timeline` 的段落；避免与主片最后一拍同义复述。
4. **少而狠**：默认 2～3 条；人确认其中 1 条为「推荐压轴」。
5. **有几轴出几轴**：`sources.json` 里有几路有效视频（closeup/wide/第三机…）就切几路**同时间码**素材，留给精剪切机位；不要只交特写。

## 听感标签（必填其一）

| `delivery` | 含义 | 典型信号 |
|---|---|---|
| `falling` | 句末降调收住，像盖章 | 句号停住；「是个 X 问题。」「才是……」 |
| `punchy` | 短、对仗、有力 | 「不仅仅是…是…」「不是…而是…」「才是」 |

不合格（不要进名单）：

- 尾音飘、疑问收尾（「是吧？」「对吧？」）
- 笑场、致谢、拖沓解释、列举腔、半截句
- 与主片结尾同义复述（如再讲一遍「个人提效≠组织提效」）

v1 **不做**音高 DSP；用词表 + 标点/停顿判断，人听单条 mp4 一票否决。字段 `delivery` 预留给日后能量包络。

## 操作方式

1. 读本场 `temp/<theme>/transcript.json`（及可选 `timeline.json` 避重）。
2. 对候选时间窗用 `scripts/dump_words_window.py` 贴词界。
3. 每条套 [`select_segment.md`](./select_segment.md)，输出 keep/drop JSON。
4. 写入 `temp/<theme>/jinju/candidates.json`（`recommended` = 推荐压轴下标，从 0 起）。
5. `scripts/run_jinju.py export --theme <主题>` → 每条金句 × 每一路源轴同时间码备选条 + 审阅稿。
6. 人确认后 `scripts/run_jinju.py pack --theme <主题>` → 推荐条焊进三条成片末尾；`jinju/` 只留备选（换结尾换最后一截）。

## 与主链关系

- **不**改 `director/prompts/`、不改主 `timeline.json` 选段。
- 主链 `cut` 后必跑本流；交付始终是三条成片 + `jinju/` 备选，无第四条。
- 机位数跟 `sources.json`（或 `sources.axes`）走：双轴交特写+全景，三轴交三路。
- 判断在 Agent 对话中完成；禁止在仓库内调外部模型 HTTP API。
